# Taller Integrador: Consumo de APIs + Power BI

##  Descripción del proyecto

Este proyecto tiene como objetivo implementar un flujo completo de análisis de datos utilizando una API pública, Python y Power BI. Se realiza la extracción, transformación y visualización de datos relacionados con películas del estudio Studio Ghibli.

---

## Herramientas utilizadas

- Python
- Jupyter Notebook (VS Code)
- Pandas
- Requests
- Power BI Desktop
- GitHub

---

## Proceso del proyecto

1. Consumo de datos desde una API pública
2. Transformación y limpieza de datos con Python
3. Creación de un dataset estructurado en formato CSV
4. Desarrollo de un dashboard en Power BI
5. Publicación de entregables en GitHub

---

## Contenido del repositorio

- Notebook con el código de extracción y transformación de datos
- Dataset en formato CSV
- Dashboard en Power BI (.pbix)
- Este archivo README con la documentación del proyecto

---

## Insight principal

“Existe una relación débil entre la duración y la calificación de las películas. Sin embargo, la calidad parece estar más influenciada por el director que por el tiempo de duración.”

---

## Conclusión

Este proyecto permite comprender un flujo real de trabajo en análisis de datos, integrando APIs, procesamiento en Python y visualización en Power BI para generar insights útiles.
